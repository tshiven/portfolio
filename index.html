UCLA Samueli School of Engineering

Caching an exact random variate generator

A speed-up layer for an exact random sampler, written in C: up to 59× faster with identical output.

C · caching · benchmarking · verification

  • Exact random samplers guarantee correct output but are slow. I wrote a cache layer in C that skips repeated work, without touching the original library.
  • Discrete distributions run 33× to 59.5× faster; continuous ones 1.3× to 1.5×.
  • Checked against the original on 33 configurations at 20,000 seeds each: output and random-bit usage matched exactly, with zero mismatches.
  • Fixed memory use, an automatic fallback to the original code path, and the limits (single-threaded, one machine) documented up front.

Fixed memory, a bounded worst case, and a safe fallback: the same constraints I want to design under on a microcontroller.
